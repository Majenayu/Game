# Owner decisions (Phase 0)

All Phase 0 decisions are answered. One item is still open: the studio name for the credits (D8c).

| ID  | Question                 | Decision                                                                                   |
| --- | ------------------------ | ------------------------------------------------------------------------------------------ |
| D1  | Game title               | **Sunfetch**                                                                               |
| D2  | Palette                  | **A, Paper Lantern** (warm amber light, deep indigo and teal), `docs/mockups/palette-A.png` |
| D3  | Renames                  | **All four:** Wick → **Tindle**, the Hush → **The Quiet**, Ember (Spirit) → **Clinker**, Time Hush → **Time Still**. Nova → **Flare** was already required. The currency stays **Embers** |

| D5  | What ends a run          | **Lives (Sparks): Cozy 5, Normal 3, Radiant 1**. A rewarded ad can revive once per run without using a Spark |
| D6  | Tech stack               | **TypeScript + Vite + Phaser 3**, with a pure TypeScript simulation for rules and balance bots |
| D7  | Git home                 | **Its own new GitHub repo** (suggested name `sunfetch`). The owner sends the URL; until then the work stays in the local repo in this folder |
| D8a | Cinder's finale choice   | **The player chooses** (ally or leave)                                                     |
| D8b | Secret ending            | Needs **10 of the 12** Souls                                                               |
| D8c | Studio name              | **Open.** The owner supplies it. It is stored in one place (`credits.studio`)               |

## Why these names (background)

- "Lanternfall" is used by at least five released or listed games (Steam, Google Play, itch.io, playlanternfall.com).
- The itch.io game Hushlight has a hero named Wick, a darkness called the Hush, and an Ember that is the hero's health
  and weapon.
- "Nova" is a character in Orb Arena, which the brief forbids reusing.
- "Glim" was considered for the hero and rejected: it is the currency in Spiritfarer and the lantern hero of the
  itch.io game PICTURE LOCK.

A web search is not a trademark check. Before launch the owner should search the trademark office for their country
(and EUIPO or USPTO if selling abroad), and search the portals' own search boxes again.
